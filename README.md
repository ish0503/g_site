# 도형 전쟁 · 기하학 전투 시뮬레이터

원, 삼각형, 사각형 같은 도형 유닛을 배치해 싸우게 하는 2D 전쟁 시뮬레이터 웹 게임입니다.
빌드 과정 없이 순수 HTML/CSS/JavaScript로 만들어져 GitHub Pages에 바로 올릴 수 있습니다.

## 실행 / 호스팅
- **로컬**: `index.html`을 브라우저로 열거나 `python3 -m http.server`로 실행
- **GitHub Pages**: 저장소 Settings → Pages → Branch를 이 브랜치(또는 main)의 `/ (root)`로 지정

## 게임 모드
- **챌린지**: 26개 스테이지. 인원 제한 안에서 유닛을 배치해 정해진 적 군대를 격파하고 골드를 얻습니다.
- **스킬 트리**: 도형 계열마다 하나의 트리 (총 7개, 100여 개 노드). 골드로 스탯 강화·특수 능력·새 유닛 해금. 언제든 전액 환불 초기화 가능.
- **샌드박스**: 제한 없이 모든 유닛(소환물 포함)을 양 팀에 배치. 대칭 복사, 랜덤 군대, 내 스킬 적용 옵션.

| ⬟ 오각형 | 마법 | 마법사, 뇌전술사, 냉기술사, 소환사, 강령술사, 운석술사 |

주요 메커니즘: 비행/대공, 물리·마법·고정 피해와 방어력, 범위·관통·연쇄·곡사 공격, 화상·독·둔화·빙결·기절,
도발, 투사체 방어, 반사·가시, 광폭화, 돌진·넉백, 도약 암살, 은신, 오라, 보호막, 치유, 소환, 시체 부활, 부활·환생, 소용돌이 등.

## 파일 구조
```
index.html
css/style.css
js/units.js    유닛 데이터
js/skills.js   스킬 트리 데이터
js/stages.js   챌린지 스테이지 데이터
js/engine.js   전투 시뮬레이션 (DOM 비의존)
js/render.js   캔버스 렌더링
js/save.js     localStorage 저장
js/ui.js       화면/조작
```
유닛·스킬·스테이지는 데이터 파일만 수정해서 쉽게 추가/조정할 수 있습니다.
