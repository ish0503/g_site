# 도형 전쟁 4.0 · 세계 전략

원·삼각형·사각형 같은 도형 유닛으로 싸우는 2D 실시간 전쟁 전략 시뮬레이터. 빌드 없이 순수 HTML/CSS/JavaScript로 동작하며 GitHub Pages에서 바로 실행됩니다.

## 4.0 세계 전략 (새 기능, 기존 모드는 그대로)
- **세계 지도**: 4개 대륙 · 16개 국가 · 120개 지역 · 40개 도시 · 14개 해역 (시드 고정 생성). 정치·군사·경제·지형 지도
- **국가 운영**: 자원 8종(식량·목재·철·석재·금·석탄·말·마력 결정), 지역 생산·세금·교역·유지비·시장, 건물 10종, 개발·도시 건설, 안정도·인력·전쟁 피로, 정치 체제 8종·국가 특성 10종
- **기술**: 군사·경제·행정·해양 4계열 × 6단계 (군사 기술은 실제 전투 능력치에 반영)
- **외교**: 동맹·방위 조약·불가침·무역·통행권·종속·독립 보장, 관계도, 전쟁 명분(핵심 영토·영유권 날조·모욕), 침략 평판, 받은 제안
- **국가 전쟁**: 선전포고와 동맹 참전, 전쟁 점수, 군단(보병·궁병·기병·공성·마법) 모집·이동·보급선·소모·공성·점령, 평화 협상(할양·배상금·종속·백지 평화), 휴전, 멸망
- **실시간 전투 연결**: 플레이어 군단의 교전은 기존 실시간 전투 엔진에서 직접 지휘(경로 탐색·전술 AI·협공·보급·탄약·요새 공성, 스킬 트리·직업 분기·장비 적용) 또는 자동 계산. 결과가 군단·전쟁 점수에 반영되고 리플레이가 보관함에 연결
- **해상 전쟁**: 항구·조선소, 전투선·수송선·보급선, 해전, 봉쇄(교역 차단), 상륙 작전, 해상 보급
- **점령지·반란**: 불안, 회유·진압·자치, 반란(진압·분리·봉기), 10년 뒤 핵심 영토 통합
- **AI 3계층**: 국가 AI(경제·외교·전쟁 판단) · 군사 AI(모집·군단·해군) · 전술 AI(실제 전투)
- **기록**: 연표·전쟁별 기여도·영토 변화 그래프·전투 목록과 리플레이
- **모드**: 세계 정복 · 국가 전쟁 · 대륙 전쟁 · 세계 대전(8개 전쟁 동시) · AI 대전 · 세계 샌드박스 · 커스텀 국가 시나리오(편집기)
- **저장**: 세계 정복은 별도 저장 슬롯(직전 판본 보존). 기존 저장 데이터는 4.0 마이그레이션 전 원본을 백업하고, 손상 시 최근 백업으로 복구

## 3.1 변경 사항
- **경로 탐색**: 20px 내비게이션 격자 + 다익스트라 흐름장(LRU 캐시) + 시야선 판정. 산맥 우회, 여울·다리 이용, 성벽이 무너지면 즉시 격자 갱신 (`js/world/nav.js`)
- **전술 AI**: 상대 편성 분석 후 상성 대응, 지형(언덕·숲) 활용, 국지 증원, 붕괴한 부대 후퇴, 핵심 목표(치유사·포병) 추적, 편성 상황별 학습 (`js/war/tactics.js`, 이전 AI는 `legacy` 로 보존)
- **리플레이**: 투사체·범위 공격·스킬 효과·피해 숫자·처치·지형 변화까지 기록, 보관함(IndexedDB 12개)·파일(.gwrep, gzip) 저장·공유 (`js/analytics/replay2.js`)
- **전투 보급**: 팀별 보급 기지(파괴 가능)와 보급량. 보급 30% 미만·고갈 시 공격력·재생·기술 회복·사기 저하, 기지에서 너무 먼 유닛은 보급선 이탈. AI가 적 기지를 습격하고 자기 기지를 방어. 전쟁 시뮬레이션·캠페인(식량 부족 시 50%로 시작)·AI 대전·샌드박스 커스텀 규칙에 적용 (`js/war/supply.js`)
- **직업 분기**: 12개 병종에 Lv5 두 갈래 → Lv10 상위 직업 두 가지(고유 기술 교체), Lv3·Lv7 특성과 조합 보너스 6종. 기존 진화는 Lv10 의 대체 선택지로 유지 (`js/progression/classes.js`)
- **성능**: 형식 배열 공간 격자, 원거리 유닛 LOD, 분리·사고 주기 조절
- **결정론적 테스트**: 전투별 시드 RNG(mulberry32), 같은 시드 → 같은 결과

## 3.0 핵심 시스템
- **전투 엔진**: 출혈·공포·혼란·침묵·속박·무적·감전, 사기와 패주, 포위, 부상, 측면·후방, 지형·날씨·시간 규칙, 파괴 가능한 성벽·성문·방어탑·성채, 동적 전장(화재 확산·크레이터·범람·낙뢰), 승리 조건(전멸·지휘관·거점·성채·보호·생존)

- **유닛**: 59종 + 소환물 + 구조물 + 보스 6종 (3.0 신규: 검투사, 기병 저지병, 철갑병, 성기사, 공성 골렘, 투창병, 포병, 주술사, 하늘 사냥꾼, 차원술사, 소멸자, 지휘관)
- **성장**: 레벨(전투 행동 기반 경험치) · 승급 · 전문화 3종 · 진화 12종 · 장비 21종(3등급) · 룬
- **경제**: 골드·식량·목재·광석·마나·수정, 캠페인 수입·유지비·보급선
- **저장**: 버전 마이그레이션(이전 데이터 자동 백업) · 10분 순환 자동 백업 · 내보내기/가져오기
