# 도형 전쟁 2.0 · 기하학 전투 시뮬레이터

원, 삼각형, 사각형 같은 도형 유닛이 싸우는 2D 실시간 군대 전략 시뮬레이터입니다.
빌드 없이 순수 HTML/CSS/JavaScript로 동작하며 GitHub Pages에 바로 배포됩니다.

## 게임 모드
- **챌린지** — 26 스테이지. 인원 제한 · 골드 보상 · 효율 보너스 · 패배 보상
- **보스 레이드** — 5종 보스 (강철 거신 · 폭풍 군주 · 심연의 마도사 · 불멸의 불사조 · 공허의 지배자), 페이즈별 패턴과 전용 공략
- **생존 모드** — 끝없이 강해지는 웨이브를 버티기
- **샌드박스 · 대규모 전쟁** — 모든 유닛·보스 자유 배치, 전장 크기 3종, 수천 기 규모 전투

## 2.0 주요 시스템
- **전투 엔진**: 상태 관리(PREPARING/RUNNING/PAUSED/FINISHED), 고정 간격 시뮬레이션과 렌더링 분리, 팀별 공간 분할, 유닛별 AI 판단 주기 분산, 질량 기반 충돌·넉백, 관성, 원형·부채꼴·직선 판정
- **AI**: `Score = w1·D + w2·T + w3·V + w4·R + w5·S` 위협도 기반 타깃 선정(역할별 가중치, 타깃 전환 히스테리시스, 협동 판단) + 역할별 행동 상태(접근·공격·후퇴·추격·보호·지원·진군·재정비)
- **진형**: 자유 · 횡대 · 방진 · 쐐기 · 원형 · 산개 · 후방 보호 — 배치 정렬, 진형 유지 진군, 빈자리 보충, 전투 효과와 약점
- **기술**: 모든 유닛 고유 기술(액티브·트리거·궁극기), 협동 기술, AI 자동 사용
- **속성**: 화염·냉기·번개·독·빛·어둠, 저항, 상성(감전, 빙결 돌파, 독 마무리, 빛 보호막 등), 측면·후방 공격
- **유닛**: 48종 + 소환물 + 보스 (2.0 신규: 검사, 결투가, 그림자 추적자, 와이번, 원소술사, 음유시인, 전술가)
- **UI**: 전투 HUD(생존 수·전투력·처치·시간·배속·진형), 유닛 상세 패널(HP·ATK·DEF·SPD·사거리·공속·치명타·저항·기술 쿨다운·AI 상태), 전투 분석(피해·받은 피해·회복·처치·기술·유닛별 효율·MVP·최장 생존·결정적 요인), 그래픽 품질 자동 조절, PC·모바일 지원

## 파일 구조
```
index.html · css/style.css
js/data/      units.js(유닛·역할·속성) tree.js(스킬 트리) stages.js abilities.js(기술) formations.js bosses.js(보스·레이드)
js/battle/    engine.js(상태·루프·공간분할) combat.js(피해 계산·투사체·범위·사망·충돌) ai.js(타깃 선정·행동)
              abilities.js(기술 실행) formation.js(진형) boss.js(보스 AI)
js/modes/     survival.js
js/render/    renderer.js (LOD·컬링·이펙트)
js/core/      save.js (1.0 저장 호환)
js/ui/        ui.js
```
유닛·기술·보스·스테이지는 `js/data/` 의 데이터만 수정해서 추가할 수 있습니다. 전투 엔진은 DOM에 의존하지 않아 Node에서도 시뮬레이션할 수 있습니다.
